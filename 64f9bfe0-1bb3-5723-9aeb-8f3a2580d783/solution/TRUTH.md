## Objective

The graded quantity is **training tokens** consumed to first reach the validation-loss target. It is not optimizer steps and it is not wallclock. Training tokens are the tokens the provided loader served to the submitted script; they are a different quantity from agent tokens, which are the LLM tokens a solving agent spends and which are never graded here.

Frozen: model_architecture, dataset_and_ordering, validation_split, evaluation_cadence, seed_set_derivation.

Free: optimizer, schedule, initialization, hyperparameters, batch_size. Batch size is free deliberately, because tokens equal steps times batch size, so freezing it would make this the steps task under another name.
