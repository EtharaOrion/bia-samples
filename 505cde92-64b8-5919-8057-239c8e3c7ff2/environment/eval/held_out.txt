The held-out split is not in this container, and this file is not it.

The graded quantity is the mean cross entropy in nats per token that the verifier
computes by running a forward pass of your trained parameter snapshot over its own
held-out FineWeb validation shards, data/fineweb10B/fineweb_val_*.bin. Those bytes
live only on the verifier side. The path to them is pinned on the verifier's admin
plane, and nothing in this container, no file and no call you can reach from it,
resolves that path or reproduces those tokens.

This file used to carry an authored evaluation split that a submission could read.
That is why it is now a notice rather than data: a split the solver can read is a
split the solver can fit, and an evaluation the solver can reproduce locally is
telemetry rather than a grade. environment/eval/folds.json declares how the
verifier partitions its split into folds. It declares the partition and carries
none of the bytes.
